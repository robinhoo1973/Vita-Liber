## 产品原则
- **隐私红线**：数据只在本机；无诊断、无用药建议；敏感媒体默认遮挡；AI 紧急情况拒答
- **永久免费**：提醒、敏感保护、离线访问、搜索、无障碍、急救卡
- **双语界面**：简体中文 / 繁體中文
