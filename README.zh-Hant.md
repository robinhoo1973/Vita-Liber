## 產品原則
- **隱私紅線**：資料僅存於本機；不提供診斷與用藥建議；敏感性媒體預設遮蔽；AI 於緊急情境一律拒答
- **永久免費**：服藥提醒、隱私保護、離線存取、搜尋、無障礙、急救卡
- **雙語介面**：簡體中文 / 繁體中文
